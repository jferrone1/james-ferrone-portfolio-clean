Next.js portfolio/resume scaffold for James Ferrone

Quick start:
1. cd portfolio-resume
2. npm install
3. npm run dev

Notes:
- The site includes a client-side "Download PDF" button that renders the resume section to PDF using html2canvas + jsPDF.
- To deploy: push to GitHub and connect the repo to Vercel (recommended).
- Customize content in components/Resume.jsx and components/Projects.jsx.
